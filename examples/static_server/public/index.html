Hical

高性能 C++20 Web 框架

Hical 是一个轻量级、零开销抽象的 C++20 Web 框架。协程驱动、零拷贝优先、 三级 PMR 内存池，在保持现代 C++ 表达力的同时，追求极致运行时性能。

  • 协程统一异步模型 —— 基于 C++20 协程 + Boost.Asio，代码像同步一样简洁
  • 零拷贝 HTTP 解析 —— string_view 直指连接缓冲区，解析过程不复制请求体
  • 三级 PMR 内存池 —— 全局池 / 线程池 / 请求级单调缓冲，请求结束整块回收
  • 洋葱模型中间件 —— 请求和响应双向拦截，天然支持 CORS / 日志 / 认证 / 限流
  • 编译期路由优化 —— 完美哈希静态路由 O(1) 查找，同步路由跳过协程帧分配
